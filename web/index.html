판별 결과와 근거

근거 ① 시간에 따른 이상도

20ms마다 노이즈 예측 오차가 진짜 음성보다 얼마나 큰지(z). 0 = 진짜 음성 평균

진짜 음성보다 오차가 큼 진짜 음성보다 오차가 작음 구간 기준을 넘은 2초 구간

아래 Mel 그림은 위치를 찾기 쉽게 깔아 둔 배경이며 모델 입력이 아닙니다. 모델은 WavLM 특징을 보며, 이 특징에는 주파수 축이 없어 "어느 주파수가 이상한지"는 말할 수 없습니다. 그림을 클릭하면 그 위치부터 재생합니다.

근거 ② 노이즈 단계별 차이

t별 구간 오차의 z-점수 평균

t가 작을수록 원본이 많이 남은 상태(세부), 클수록 노이즈가 많이 섞인 상태(큰 구조)에서 본 차이입니다. 음수는 진짜 음성보다 오차가 작다는 뜻이며, 지나치게 매끄러운 합성 음성에서 나타날 수 있습니다.

근거 ③ 분포 거리 기여

진짜 음성 분포와의 거리(Mahalanobis)를 이룬 특징

오차가 크든 작든 진짜 음성의 "보통 모양"에서 벗어나면 거리가 커집니다. 기여율은 거리²에서 각 특징이 차지하는 몫입니다.

      처리하는 정보
      올리거나 녹음한 음성 내용과 파일 확장자. 파일 이름은 서버로 보내지 않습니다. 서버는 접속 기록(IP 주소, 요청 주소)을 남기지 않습니다.
      목적
      딥보이스(합성 음성) 여부 판별과 판단 근거 설명. 화자를 식별하거나 모델 학습에 쓰지 않습니다.
      처리 방식
      음성은 분석 서버의 메모리에서만 처리하고 디스크에 저장하지 않습니다. 단, 일부 m4a·mp4 파일처럼 메모리에서 바로 읽을 수 없는 경우에만 디코딩 중에 임시 파일을 만들고 읽자마자 삭제합니다. 임시 파일을 썼는지는 결과와 보고서에 표시됩니다.
      보관 기간
      서버: 보관하지 않음(응답 직후 파기). 브라우저: 결과는 이 탭의 메모리에만 있으며, '결과 지우기'를 누르거나 탭을 닫으면 사라집니다. 브라우저 저장소(쿠키, localStorage)는 쓰지 않습니다.
      제3자 제공·외부 전송
      없음. 이 화면은 외부 글꼴·스크립트·분석 도구를 불러오지 않으며, 보안 설정으로 분석 서버 외의 곳에는 연결할 수 없습니다.
      보고서
      사용자가 요청할 때 이 브라우저 안에서 만들어집니다. 파일 이름, 파일 지문, Mel 그림은 기본값으로 빠져 있으며 직접 선택할 때만 들어갑니다. 내려받은 보고서는 사용자가 직접 관리하고, 필요 없어지면 삭제하세요.
